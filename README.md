# 🌸 Gopa Tech — Ecommerce de Accesorios de Escritorio

Sitio web de ecommerce desarrollado con HTML5 y CSS3 como parte de la pre-entrega del curso de Front-End JS de Talento Tech.

## ¿De qué se trata?

Gopa Tech es una tienda online de accesorios de escritorio aesthetic y cute: teclados, mousepads, auriculares, lámparas y más. La idea es combinar funcionalidad con un diseño colorido y divertido para personas que quieren que su setup sea tan lindo como productivo.

## Estructura del proyecto

```
gopa-tech/
├── index.html        → Página principal
├── tienda.html       → Catálogo de productos
├── contacto.html     → Formulario de contacto y ubicación
├── styles.css        → Estilos generales
├── contacto.css      → Estilos específicos de contacto
└── img/              → Imágenes de productos
```

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts 
- Formspree para el formulario de contacto
- Google Maps iframe

## Proceso de construcción

El proyecto fue tomando forma de a poco, página por página. La parte técnica —estructura HTML, Flexbox, Grid y Media Queries— no presentó grandes dificultades gracias a lo visto en clase.

El mayor desafío fue el lado creativo: decidir qué tipo de tienda hacer, qué paleta de colores usar y cómo lograr que el diseño transmitiera la identidad de la marca. La paleta pastel (creamsicle, ibis pink, indigo child, paris pink y mauve memento) fue una decisión que llevó su tiempo pero valió la pena.

Las imágenes de productos fueron buscadas y seleccionadas manualmente para que fueran coherentes con la estética de la tienda.

Durante el desarrollo usé IA como asistente principalmente para trabajar las Media Queries y asegurarme de que el diseño respondiera correctamente en distintos tamaños de pantalla. También fue útil para discutir decisiones de estructura y organización del proyecto.
